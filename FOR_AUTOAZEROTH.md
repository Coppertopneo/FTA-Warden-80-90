# Note for AutoAzeroth

This is an experimental integration built around Follow The Arrow's optimized
80–90 route and WardenGG movement/object APIs.

The author is happy to provide the work to the AutoAzeroth team for free and
does not expect payment or compensation.

The current useful milestone is not theoretical: the v0.4 prototype has been
tested in game and has flown to the FTA destination, landed directly in front
of the NPC, identified the live object, approached it, and opened the quest
dialog.

The current missing piece is explicit quest-dialog acceptance/completion.

The project is also evaluating whether AutoAzeroth's navigation architecture
already solves the MMAP/VMAP hosting/pathfinding problem, to avoid duplicating
work unnecessarily.
